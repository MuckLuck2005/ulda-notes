# Architecture

## General structure
The project is a static landing page for the bachelor thesis project ULDA Notes.

## Main components
- `index.html` — page structure and semantic content
- `css/style.css` — styling, typography and responsive layout
- `js/main.js` — navigation interaction and page behavior
- `generated-docs/` — generated API documentation from JSDoc comments

## Design decisions
The JavaScript logic is separated into small named functions to improve readability, maintainability and automatic documentation generation.
